# Система учета ремонта техники

Проект для Visual Studio 2022.

## Технологии
- C#
- ASP.NET Core Web API
- REST API
- JSON
- Swagger

## Возможности
- Добавление заявок
- Просмотр заявок
- Изменение заявок
- Удаление заявок
- Хранение данных в JSON

## Запуск
1. Открыть файл RepairSystem.sln
2. Нажать Start
3. Swagger откроется автоматически
